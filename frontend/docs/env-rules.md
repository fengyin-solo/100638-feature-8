# 廊内环境监测判定规则（唯一口径）

> 本文件与 `src/domain/env-rules.ts` 是同一套口径的文字版与代码版。
> 条件、阈值、上限如需修改，先改口径表（`METRIC_SPECS`）并升 `RULE_VERSION`，
> 页面、回填、联动、复核任何地方都不允许再抄一份数字。

依据：GB 50838《城市综合管廊工程技术规范》7.5 环境与设备监控、GBZ 2.1 作业场所有害因素限值。

## 1. 点位标准范围登记

每个监测点位登记四项指标的标准闭区间 `[min, max]` 与所属舱室；
未登记标准的点位禁止采集入库。标准范围必须落在仪表硬量程内，且下限 < 上限。

| 指标 | 单位 | 硬量程（取值上下限） | 默认标准范围 | 一级预警带宽 |
| --- | --- | --- | --- | --- |
| 环境温度 | ℃ | -40 ~ 80 | 5 ~ 40 | 5℃ |
| 空气湿度 | %RH | 0 ~ 100 | 30 ~ 90 | 5%RH |
| 氧气浓度 | %VOL | 0 ~ 30 | 19.5 ~ 23.5 | 1.0%VOL |
| 有害气体浓度 | ppm | 0 ~ 100 | 0 ~ 10 | 10ppm |

## 2. 统一分档（四个指标同一套条件）

1. 实测值在标准闭区间内（含等号边界）→ **正常**；
2. 越界，且越过最近边界的距离 `excess ≤ warnBand` → **一级预警**；
3. 越界，且 `excess > warnBand` → **二级超标**。
4. 单元格无法参与判定 → **缺失**。

点位整体结论（就高不就低）：

- 四项全缺失 → **待采集**；
- 有值但存在缺失项 → **指标缺失**（状态落“已采集”，绝不允许记正常）；
- 四项齐全且全正常 → **指标正常**；
- 否则取最高档位 → **一级预警 / 二级超标**（状态均落“指标超标”）。

## 3. 不允许保存的取值（禁存清单，唯一一份）

- `null` / `undefined` / 空串 / 纯空白；
- 非数值文字（如早年的“正常”“--”）；
- `NaN` / `Infinity`；
- 越过硬量程（含 -40℃、80℃、100%RH、30%VOL、100ppm 之外的值）。

实时报送命中禁存 → 整笔拒收，不写任何数据。
历史回填命中禁存 → 该单元格清洗为留空并在“残缺字段”标出，不补零、不猜数。

## 4. 两条入库路径的先后与冲突兜底（裁决依据）

- **路径 A 现场实测**、**路径 B 复核补录** 共用同一事务管道。
- 唯一键 = 监测点位 + 采集时间；同键重复报送 **只认最后一版**。
- 来源优先级：**现场实测(1) > 复核补录(2) > 历史回填(3)**。
  两处取值打架时以现场实测那份为准，其它入口保存的值按现场实测重算；
  低优先级来源不允许覆盖高优先级旧版（整笔拒绝）。
- 存量回填是对存量自身的一次性重判，不受冲突兜底拦截；记录原有来源保留。

## 5. 通风联动

- 只有 **二级超标** 牵动通风；一级预警仅提示。
- 按**超标舱室**对账：每个舱室至多一条“待开机”联动任务，
  同一舱室新增的超标记录挂到同一任务（不重复排）。
- 任务关联的超标记录全部恢复正常/被实测纠正后，任务自动撤回（置已停机留痕）。

## 6. 历史记录回填

- 应用启动时执行一次性迁移；也可在页面按钮手动触发（幂等）。
- 按**采集时间升序**逐条走与报送相同的管道（去重折叠 → 清洗 → 判定 → 通风对账 → 复核回写），
  批次统一标记 `2026-10-06 历史回填`。
- “早年把未采集写成正常”的识别裁决：**不看旧状态文字，只看四个单元格**——
  四项全不合法即“未采集写成正常”的那几条，判待采集；部分不合法判指标缺失。

## 7. 复核一致性与事务保证

- 每条环境记录回写一行复核项（记录 id + 口径版本）；复核清单展示时按现值实时重算，
  与环境列表、详情面板调用的是同一个纯函数 `evaluateRow`，两处结论必然一致。
- 登记/报送/回填/联动/复核在**同一个整笔事务**内提交：
  克隆草稿 → 改 → 整串写 localStorage → **回读逐字节比对** → 才切换只读快照；
  任一步失败保留旧快照，等同整笔退回。
- 读出的快照整体冻结（`Object.freeze`），前后两次读到的是同一份数据。
